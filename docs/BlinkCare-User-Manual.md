## คำนำ

คู่มือฉบับนี้จัดทำขึ้นเพื่ออธิบายการใช้งานระบบ BlinkCare ตั้งแต่การสมัครสมาชิก การติดตั้งส่วนประกอบสำหรับตรวจจับ การเริ่มและสิ้นสุดการตรวจจับ ตลอดจนการอ่านผลลัพธ์ การสร้างแผนดูแลดวงตา และการตั้งค่าการแจ้งเตือน เพื่อให้ผู้ใช้งานสามารถใช้งานระบบได้อย่างถูกต้องและเข้าใจข้อมูลที่ระบบนำเสนอ

BlinkCare เป็นเครื่องมือช่วยติดตามพฤติกรรมระหว่างใช้งานคอมพิวเตอร์ ระบบประเมินอัตราการกะพริบตา ระยะเวลาใช้งานหน้าจอ ช่วงเวลาที่มีความเสี่ยง และการใช้งานแอปพลิเคชัน ข้อมูลดังกล่าวใช้สำหรับสนับสนุนการปรับพฤติกรรมเท่านั้น ไม่ใช่การวินิจฉัยหรือคำแนะนำทางการแพทย์

# 1. ภาพรวมและส่วนประกอบของระบบ

BlinkCare ประกอบด้วย 3 ส่วนที่ทำงานร่วมกัน ได้แก่

1. **เว็บไซต์ BlinkCare** ใช้เริ่มหรือควบคุมการตรวจจับ ดูข้อมูล สร้างแผน และตั้งค่าระบบ
2. **BlinkCare Chrome Extension** ใช้ตรวจจับการกะพริบตาผ่านกล้องและแสดงการแจ้งเตือนนอกแท็บเว็บไซต์
3. **Blink Helper** ใช้ตรวจสอบชื่อแอปพลิเคชันที่กำลังใช้งาน เพื่อสรุประยะเวลาและอัตราการกะพริบตาแยกตามแอป

ผู้ใช้ต้องเข้าสู่ระบบด้วยบัญชีเดียวกัน และเปิด Blink Helper พร้อมติดตั้ง Extension ก่อนเริ่มตรวจจับ

> ภาพที่ 1-1 หน้า Overview ของระบบ BlinkCare

# 2. การสมัครสมาชิกและเข้าสู่ระบบ

## 2.1 การสมัครสมาชิก

1. เปิดเว็บไซต์ BlinkCare และเลือก **ลงทะเบียน**
2. กรอกชื่อผู้ใช้ อีเมล รหัสผ่าน และยืนยันรหัสผ่าน
3. เลือก **สร้างบัญชี**
4. เมื่อสร้างบัญชีสำเร็จ ระบบจะพาไปยังหน้าเข้าสู่ระบบ

> ภาพที่ 2-1 หน้าสมัครสมาชิก

## 2.2 การเข้าสู่ระบบด้วยอีเมล

1. กรอกอีเมลและรหัสผ่าน โดยอีเมลไม่แยกตัวพิมพ์เล็กและตัวพิมพ์ใหญ่
2. เลือก **เข้าสู่ระบบ**
3. กรอกรหัส OTP จำนวน 6 หลักที่ได้รับทางอีเมล
4. ตรวจสอบเลข **Ref** บนหน้าเว็บไซต์ให้ตรงกับอีเมล
5. เลือก **ยืนยันรหัส OTP**
6. หากไม่ได้รับรหัส ให้รอเวลานับถอยหลังแล้วเลือก **ส่ง OTP ใหม่**

> ภาพที่ 2-2 หน้าเข้าสู่ระบบ  
> ภาพที่ 2-3 หน้ายืนยัน OTP และเลข Ref

## 2.3 การเข้าสู่ระบบด้วย Google

1. เลือก **Continue with Google**
2. เลือกบัญชี Google ที่ต้องการเชื่อมต่อ
3. ยืนยันสิทธิ์การเข้าสู่ระบบ
4. ระบบจะนำกลับมายัง BlinkCare โดยอัตโนมัติ

> ภาพที่ 2-4 ปุ่มเข้าสู่ระบบด้วย Google

# 3. การดาวน์โหลดและติดตั้ง BlinkCare

1. เลือกเมนู **Downloads**
2. ดาวน์โหลด Blink Helper ให้ตรงกับระบบปฏิบัติการ Windows หรือ macOS
3. ติดตั้งและเปิด Blink Helper
4. ดาวน์โหลดไฟล์ Chrome Extension และแตกไฟล์ ZIP
5. เปิด `chrome://extensions` ใน Google Chrome
6. เปิด **Developer mode**
7. เลือก **Load unpacked** แล้วเลือกโฟลเดอร์ Extension ที่แตกไฟล์ไว้
8. อนุญาต Site access สำหรับเว็บไซต์ BlinkCare
9. กลับมายังหน้า Downloads และเลือก **ตรวจสอบอีกครั้ง**

สถานะ Chrome Extension และ Blink Helper ต้องแสดงว่าเชื่อมต่อแล้วก่อนเริ่มตรวจจับ

> ภาพที่ 3-1 หน้าดาวน์โหลดและสถานะส่วนประกอบ  
> ภาพที่ 3-2 หน้า `chrome://extensions` ขณะเปิด Developer mode  
> ภาพที่ 3-3 Extension ที่ติดตั้งสำเร็จ

# 4. การตรวจสอบอุปกรณ์ที่เชื่อมต่อ

1. เลือกเมนู **Connecting Device**
2. ตรวจสอบว่าระบบพบกล้องและได้รับสิทธิ์ใช้งานกล้อง
3. ตรวจสอบสถานะ Chrome Extension
4. ตรวจสอบสถานะ Blink Helper และชื่อแอปที่กำลังใช้งาน
5. ตรวจสอบการเชื่อมต่อ Production API
6. หากสถานะไม่อัปเดต ให้เลือก **ตรวจสอบระบบทั้งหมด**

หน้านี้ไม่แสดงภาพจากกล้อง เพื่อรักษาความเป็นส่วนตัวของผู้ใช้

> ภาพที่ 4-1 หน้าอุปกรณ์ที่เชื่อมต่อซึ่งมีสถานะปกติทั้งหมด

# 5. การตรวจจับการกะพริบตาแบบเรียลไทม์

## 5.1 การเริ่มตรวจจับจากเว็บไซต์

1. เลือกเมนู **Realtime**
2. เลือก **เริ่มการตรวจจับ**
3. อนุญาตใช้กล้อง หากเบราว์เซอร์ร้องขอสิทธิ์
4. รอให้ระบบปรับค่า Baseline ของดวงตา
5. เมื่อพบใบหน้า ระบบจะเริ่มนับเวลาที่ใช้งานจริงและจำนวนการกะพริบตา

หากไม่พบ Extension หรือ Helper ระบบจะแจ้งเตือนและนำไปยังหน้าดาวน์โหลด ไม่สามารถเปิด Detection Session ซ้ำจากเว็บไซต์และ Extension พร้อมกันได้

> ภาพที่ 5-1 หน้า Realtime ก่อนเริ่มตรวจจับ  
> ภาพที่ 5-2 หน้า Realtime ขณะกำลังตรวจจับ

## 5.2 การหยุดชั่วคราวและดำเนินการต่อ

1. เลือก **หยุดชั่วคราว** เมื่อต้องการพักการตรวจจับ
2. เลือก **ดำเนินการต่อ** เมื่อต้องการกลับมาตรวจจับ
3. หากระบบไม่พบใบหน้า เวลาที่ใช้งานจริงจะหยุดนับชั่วคราว และนับต่อเมื่อพบใบหน้าอีกครั้ง

> ภาพที่ 5-3 สถานะหยุดชั่วคราวหรือไม่พบใบหน้า

## 5.3 การสิ้นสุด Session

1. เลือก **สิ้นสุดการตรวจจับ**
2. ระบบบันทึกจำนวนการกะพริบตา อัตราการกะพริบตา เวลาหน้าจอ และข้อมูลแอปที่ใช้งาน
3. ข้อมูลจะแสดงใน Dashboard และ History ของบัญชีที่เข้าสู่ระบบ

> ภาพที่ 5-4 สรุปผลหลังสิ้นสุด Session

## 5.4 การเริ่มตรวจจับจาก Extension

1. เปิด BlinkCare Extension จากแถบเครื่องมือ Chrome
2. ตรวจสอบว่าบัญชีเชื่อมต่อแล้วและ Blink Helper พร้อมใช้งาน
3. เลือก **เริ่มตรวจจับ**
4. สามารถดูจำนวนการกะพริบตา EAR เวลา และชื่อแอปที่กำลังใช้งานจาก Popup
5. สถานะและข้อมูลสดจะแสดงบนหน้า Realtime ของเว็บไซต์ด้วย

> ภาพที่ 5-5 Popup ของ Extension ขณะกำลังตรวจจับ

# 6. การดูภาพรวมรายวัน

1. เลือกเมนู **Dashboard > ภาพรวมรายวัน**
2. เลือกวันที่ต้องการตรวจสอบ
3. ตรวจสอบระดับ **Dry Eye Risk**, จำนวนการกะพริบตา, จำนวนแอปที่ใช้, อัตราการกะพริบตาเฉลี่ย และเวลาหน้าจอ
4. ดูแนวโน้ม Blink Rate แยกตามช่วงเวลา
5. ดูช่วงเวลาหรือแอปที่มีความเสี่ยงสูงจาก Top Risk Periods
6. ดู App Usage Summary และรายการ Detection Session ของวันนั้น

ค่าที่แสดงบนกราฟเป็นค่าเฉลี่ยถ่วงน้ำหนักตามระยะเวลาของข้อมูลในช่วงนั้น จึงอาจไม่เท่ากับค่าเฉลี่ยราย Session แบบไม่ถ่วงน้ำหนัก

> ภาพที่ 6-1 Dashboard ภาพรวมรายวันทั้งหน้า

---

# 7. การดูภาพรวมหลายวัน

1. เลือกเมนู **Dashboard > ภาพรวมหลายวัน**
2. เลือกช่วง 7 วันหรือ 30 วัน
3. ตรวจสอบ Eye Health Score ซึ่งคำนวณจาก Blink Health, Continuous Use, Break Behavior และ Risk Exposure
4. เปรียบเทียบ Blink Rate กับช่วงเวลาก่อนหน้า
5. ตรวจสอบ Heatmap ความเสี่ยงรายวัน ช่วงเวลาที่เสี่ยงที่สุด ผลของแผน และ Insight
6. ในมุมมอง 30 วัน สามารถลาก Heatmap ในแนวนอนเพื่อดูวันอื่นได้

เกณฑ์ Eye Health Score:

- 80–100: พฤติกรรมดูแลดวงตาดี
- 60–79: เริ่มมีพฤติกรรมเสี่ยง
- 0–59: มีพฤติกรรมเสี่ยงหลายช่วง ควรพักและปรับพฤติกรรม

> ภาพที่ 7-1 ภาพรวมหลายวัน ช่วง 7 วัน  
> ภาพที่ 7-2 ภาพรวมหลายวัน ช่วง 30 วัน

# 8. การสร้างและจัดการแผนดูแลดวงตา

## 8.1 การสร้างแผน

1. เลือกเมนู **Plan** แล้วเลือก **สร้างแผนใหม่**
2. ตั้งชื่อแผนและเลือกเป้าหมาย
3. เปิดมาตรการที่ต้องการและกำหนดรอบเวลา
4. สำหรับกฎ 20-20-20 เลือกได้ระหว่าง **ยืดหยุ่น** และ **ตามแผน**
5. กำหนดวันเริ่มต้นและสิ้นสุด
6. ตรวจสอบตัวอย่างแผน แล้วเลือก **บันทึกแผน**

โหมดยืดหยุ่นจะนับเฉพาะเวลาที่ตรวจพบผู้ใช้อยู่หน้าจอ ส่วนโหมดตามแผนจะแจ้งตามรอบเวลาที่กำหนดในมาตรการ

> ภาพที่ 8-1 หน้ารวมแผนของฉัน  
> ภาพที่ 8-2 หน้าสร้างแผนและเลือกมาตรการ

## 8.2 การดูรายละเอียดและแก้ไขแผน

1. เลือกแผนที่ต้องการ
2. เลือก **ดูรายละเอียด** เพื่อดูผลแยกตามมาตรการ
3. เลือก **แก้ไขแผน** เมื่อต้องการเปลี่ยนชื่อ ระยะเวลา หรือมาตรการ

> ภาพที่ 8-3 รายละเอียดมาตรการของแผน

---

# 9. การติดตามผลตามแผน

1. เลือกแท็บ **ติดตามผล**
2. เลือกชื่อแผนที่ต้องการดู
3. เลือกช่วงข้อมูล วันนี้, 7 วัน, 30 วัน หรือทั้งหมด
4. ตรวจสอบจำนวนรอบที่เกิดขึ้น ทำสำเร็จ ข้าม และจำนวนวันที่ใช้งาน
5. ดูผลแยกตามมาตรการ การทำตามแผนรายวัน และสรุปการใช้งาน
6. เปรียบเทียบ Blink Rate และเวลาใช้งานหน้าจอกับช่วงก่อนเริ่มแผน

> ภาพที่ 9-1 หน้าติดตามผลของแผน

---

# 10. การดูประวัติย้อนหลัง

1. เลือกเมนู **History**
2. เลือกวันที่หรือช่วงวันที่ที่ต้องการ
3. เลือกตัวกรอง ทั้งหมด, การใช้งาน, การแจ้งเตือน หรือการพักสายตา
4. ตรวจสอบ Timeline ของเหตุการณ์ย้อนหลัง
5. ดูเหตุการณ์ที่น่าสนใจ เช่น Blink Rate ต่ำกว่าเกณฑ์ ใช้งานหน้าจอต่อเนื่องนาน หรือสภาพแสงไม่เหมาะสม

> ภาพที่ 10-1 หน้าประวัติย้อนหลังและ Timeline

---

# 11. การตั้งค่าการแจ้งเตือน

1. เลือกเมนู **Notification**
2. เปิดหรือปิดการแจ้งเตือน Blink Rate ต่ำกว่าค่ามาตรฐาน
3. เปิดหรือปิดการแจ้งเตือนเมื่อไม่พบใบหน้า
4. เปิดหรือปิดการแจ้งเตือนเมื่อสภาพแสงไม่เหมาะสม
5. เปิดหรือปิดการแจ้งเตือนเมื่อทำตามแผนสำเร็จ
6. เลือกปิดเสียง หากไม่ต้องการเสียงแจ้งเตือน
7. บันทึกการตั้งค่า

เมื่ออนุญาต Notification ของ Chrome แล้ว การแจ้งเตือนสามารถแสดงนอกแท็บเว็บไซต์ผ่าน Extension ได้

> ภาพที่ 11-1 หน้าตั้งค่าการแจ้งเตือน  
> ภาพที่ 11-2 ตัวอย่างการแจ้งเตือนจาก Extension

# 12. การออกจากระบบ

1. เลือกชื่อผู้ใช้บริเวณด้านล่างของ Sidebar
2. เลือก **ออกจากระบบ**
3. ระบบจะยกเลิก Token ของบัญชีและกลับไปยังหน้าแรก

> ภาพที่ 12-1 เมนูบัญชีและปุ่มออกจากระบบ

- ตรวจสอบว่า Extension เปิดใช้งานอยู่ใน `chrome://extensions`
- กด Reload ที่ Extension แล้ว Refresh เว็บไซต์
- ตรวจสอบ Site access ว่าอนุญาตเว็บไซต์ BlinkCare

## ไม่พบ Blink Helper

- เปิด Blink Helper ในเครื่อง
- ตรวจสอบว่าไม่มี Firewall ปิดกั้น Local Helper
- กลับไปหน้า Connecting Device แล้วตรวจสอบระบบอีกครั้ง

## กล้องไม่ทำงาน

- อนุญาตสิทธิ์ Camera ให้ Chrome
- ปิดโปรแกรมอื่นที่กำลังใช้กล้อง
- เลือกกล้องใหม่จากหน้า Connecting Device

## เวลาไม่เดิน

- ตรวจสอบว่าใบหน้าอยู่ในกรอบและมีแสงเพียงพอ
- เวลาจะหยุดโดยอัตโนมัติเมื่อไม่พบใบหน้า

## ไม่ได้รับ OTP

- ตรวจสอบอีเมลและโฟลเดอร์ Spam
- ตรวจสอบเลข Ref ของข้อความล่าสุด
- รอครบ 60 วินาทีแล้วเลือกส่ง OTP ใหม่

## ภาพเสริมที่ควรมีหากต้องการอธิบายละเอียด

- Popup แจ้งเตือนว่าต้องติดตั้ง Extension และ Helper ก่อนเริ่มตรวจจับ
- หน้าจอเลือก Load unpacked
- หน้าจอขอสิทธิ์กล้องของ Chrome
- หน้า Plan ขณะเลือกโหมดยืดหยุ่นและตามแผน
- หน้ารายละเอียดผลรายมาตรการ
- ตัวอย่างอีเมล OTP ที่เห็นรหัสและ Ref ตรงกับเว็บไซต์
- ตัวอย่างข้อความ Error เมื่อ OTP ไม่ถูกต้องหรือหมดอายุ

## แนวทางการแคปภาพ
